# hosts/hlsl: the modern HLSL host

`hogshade_core.hlsl` is the shading core as shader-model 6 HLSL, generated by naga from `core/*.wgsl`
through `tools/build_shaders.py`, formatted by naga, and validated with dxc (`ps_6_0`) on every
change; CI fails if it is stale. It is what an Unreal custom node, a Unity shader, a DX12 sample or
anyone who reads HLSL consumes. Do not edit it: edit the WGSL and rebuild. The Maya shell includes
the shader-model 5 output of the same build (`hosts/maya_dx11/generated/hogshade_core_sm5.hlsl`),
not this file.

## Binding layout: there is none

The core declares no `cbuffer`, no `Texture2D`, no `SamplerState` at file scope. Every texture,
sampler and constant is a **function parameter**. A consumer declares its own resources in its own
register spaces and passes them in; nothing in this file competes for a register. That is the rule
the phase 2 spike established (naga's global bindings become a sampler heap in register spaces
that an effect shell cannot bind) and it is what makes the same file usable from an `.fx` shell,
a DX12 root signature and a Unity pass alike.

## What to call

| Need | Function | Notes |
| --- | --- | --- |
| Build the material half for the legacy v2 model | `legacy_v2_inputs(legacy_v2_Material, legacy_v2_Samples, legacy_v2_Geometry) -> ShadingInputs` | fill the three structs from your parameters, texel values (or the unbound defaults in the struct comments) and vertex data |
| Lookup coordinates for the environment | `models_env_lookup(ShadingInputs) -> float2` | (n.v, roughness) the model wants for the LUT and prefiltered mip |
| Sample the E1 environment | `environment_sample(TextureCube<float4> specular, TextureCube<float4> irradiance, Texture2D<float4> lut, SamplerState cube, SamplerState lut, EnvironmentIBL, float3 n, float3 v, float2 lookup) -> EnvironmentSamples` | `environment_default(mip_count)` builds the constants; set `.exposure` |
| Hemisphere dome (v2) | `environment_hemisphere(sky, ground, n, up) -> float3` | assign to `EnvironmentSamples.hemisphere` and set `.hemisphere_mode` |
| Lights | `lighting_slots_empty() -> FixedSlots16_`, then fill `light[k]` and `count` | `LightSource` field order and offsets are in `core/interface.wgsl`; `kind` 1 directional (towards the light), 2 point, 3 spot |
| Shade | `models_shade(ShadingInputs, FixedSlots16_, EnvironmentSamples, uint debug_mode) -> ShadingResult` | `.color` is scene-linear radiance; `.debug` the selected view |
| Per-light, for an engine's own loop | `models_evaluate_light(ShadingInputs, LightSource, EnvironmentSamples) -> float3` | sum over your culled list, then add `models_evaluate_env` and emissive |
| Deferred | `gbuffer_encode_from_inputs`, `gbuffer_decode_adr002`, `gbuffer_reconstruct` | ADR-002 layout, `core/gbuffer.wgsl` |
| Debug views a host must answer itself | `legacy_v2_debug_is_inputs_mode(uint)`, `legacy_v2_debug_inputs(...)` | the twelve texel and UV modes; see `core/models/legacy_v2.wgsl` |

naga appends an underscore to names that end in a digit (`FixedSlots16_`, `specular_f0_`,
`sh9_`, `gb0_`); the struct definitions at the top of the file are authoritative.

## Worked example

`hosts/maya_dx11/hogshade.fx` is the complete example: Maya-annotated parameters, sixteen light
slots filled into `FixedSlots16_`, cubes and the LUT passed into `environment_sample`, and the
`models_shade` call. `hosts/wgpu/common.wgsl` is the same shape in WGSL.
